# Scheme libraries

This folder contains many of the builtin libraries here is ease interacting with the bindings.

Unfortunatly, `steel` does not seems to support documentation for things like macros or re-export, hence why the `help` function returns nothing on them. Documentation for such things is inlined in the files.

## Documentation

- **Functions** carry their docs in `@doc` blocks built by `cv-help`, so
  `(help name)` works for every callable function of these libraries.
- **Macros, sorts and plain values** cannot hold `help` docs. Their
  documentation lives in a small table registered *right next to the
  definition*, in the library that owns it: a `(register-syntax-doc! 'name
  "para" ...)` / `(register-type-doc! 'name "para" ...)` call. Each library
  owns and exports its table (`function-doc`, `formula-doc`, ...); the shallow
  helpers (`make-doc-table`, `doc-add!`) live in `cryptovampire/doc`.

  Why per-library tables?  Steel module instances are shared, but
  `require`/`provide` copy *values*: an imported binding is a snapshot that
  does not track later `set!`s, so live module state is only observable
  through closures (functions) defined in that module.  A single registry
  imported as a value would thus go stale once the registering libraries run
  (whereas a registry read through an accessor closure would stay live, like
  `get-function` over `functions-map`).  Building one table per library and
  exporting it *finished* needs no live sharing at all; `builtin-doc` in
  `cryptovampire/builtin-functions` follows the same shape.
- **Rust-exported builtins** (`cryptovampire/builtin-functions`, generated by
  `mk_scheme_lib`) inherit the `///` doc comment of their unwrapped function:
  each wrapper is a distinct closure carrying that doc, so `(help mand)` works,
  and the module also exports the `builtin-doc` table for the doc generator.
- `../docgen.scm` assembles `docs/scheme-api.md` (a gitignored generated file)
  from the `help` tables and the per-library doc tables.  Regenerate from the
  repository root with:

  ```sh
  cargo run --release -- crates/indistinguishability/scheme/docgen.scm
  ```
