# Cryptovampire examples

This folder contains example for the trace cryptovampire.

## Few notes
- all theses examples *can* be proven, but they can be quite fikle. Tankfully, an SMT run longer than a second can typocally be considered failed. Some examples require 2 runs.
- This version of cryptovampire does not support having mutliple protocol defined, so when we want to prove a property for two compatible protocols, we need two files
